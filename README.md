# 1on1app

## Best Buy Options Selector

This simple web app helps you rank and pick the best purchase option based on price, rating, and value.

### Run locally

Open `index.html` in your browser or serve the folder with a local static server.

### How it works

1. Add options with a price, rating, and value score.
2. Adjust the weights to reflect what matters most to you.
3. The highest combined score becomes the recommended pick.
